# ObjectEditor

Egy egyszerű, böngészőben futó objektum-szerkesztő eszköz, amely HTML, CSS és JavaScript segítségével készült.

## Funkciók

- Objektumok (JSON alapú adatok) létrehozása, szerkesztése és megtekintése
- Valós idejű szerkesztés a böngészőben
- Egyszerű és letisztult felhasználói felület
- Teljesen kliensoldali működés (nincs szerveroldali backend szükséges)
- Adatok exportálása / importálása (JSON)

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript** (nincs külső függőség)

## 🚀 Használat

1. Töltsd le a repository-t vagy klónozd:

```bash
git clone https://github.com/Snewkovits/ObjectEditor.git
```

Nyisd meg az index.html fájlt bármely modern böngészőben (Chrome, Firefox, Edge stb.).

Kész! Nincs telepítés vagy szerver indítása szükséges.
